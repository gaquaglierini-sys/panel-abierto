Datos

Gasto de Meta Ads

En el Administrador de anuncios: nivel Anuncios (o Campañas) → Desglose → Por tiempo → Día → Exportar → CSV. Debe traer Día, Nombre de la campaña e Importe gastado; con Nombre del anuncio, las alertas van anuncio por anuncio.

Ventas

Se necesita una columna de fecha y una de monto. Con utm_campaign (o src en Hotmart, referencia externa en Mercado Pago) cada venta va a su oferta; con utm_content (o sck), a su anuncio. Si hay columna de estado, se cuentan solo las ventas aprobadas o pagadas.

Plantillas para probar: Meta Ads · Impultienda · Hotmart · Mercado Pago · Stripe. Al importar un archivo se reemplazan los datos de esa misma plataforma en esas fechas: se puede volver a subir sin duplicar nada ni pisar las otras.

Lee el gasto por anuncio directo de la API de Marketing de Meta. La clave queda solo en esta pestaña y se borra al cerrarla. Se obtiene en developers.facebook.com → Herramientas → Explorador de la API Graph, con el permiso ads_read.

Cada oferta junta las campañas cuyo nombre contiene alguno de sus textos (sin importar mayúsculas ni tildes). La misma regla vale para el utm_campaign de las ventas.

Las reglas marcan cada anuncio con una acción. Se revisan de arriba hacia abajo: la primera que se cumple decide. Todas las condiciones de una regla tienen que cumplirse a la vez. Los montos van en USD.

Todo se muestra en dólares. Indica cuántas unidades de cada moneda equivalen a 1 USD. Las tasas que vienen son de ejemplo: actualízalas con la cotización que uses.

El asistente usa tu propia clave de la API de Claude (se crea en console.anthropic.com → API Keys). La consulta va directo de este navegador a api.anthropic.com y el uso se cobra en tu cuenta de Anthropic. La clave nunca se sube a ningún otro lado ni se incluye en los respaldos.

Todo se guarda en este navegador. Descarga un respaldo para pasarlo a otra computadora (no incluye claves).
